01 IoT industrial · Projeto profissional · Projeto principal

SALVE - Sistema Assistivo à Lactação e Vigilância contra Esmagamento

Solução IoT industrial distribuída para monitoramento em ambiente agroindustrial, integrando sensoriamento, comunicação LoRaWAN, processamento local, gerenciamento de alertas, interface gráfica, dispositivo vestível (ESP32- SALVE Sentinel), persistência local e remota, sincronização com cloud, processamento em nuvem e dashboard administrativo.

02 Embedded · ESP32 · Wearable

SALVE Sentinel - LilyGO T-Watch-S3

Dispositivo vestível baseado no T-Watch-S3 para recebimento de alertas operacionais, combinando firmware embarcado, comunicação LoRaWAN, display, vibração e gerenciamento de energia. O wearable integra o fluxo de resposta do SALVE em campo.

04 Full Stack · Deploy público · Portfólio

Fullstack Authentication Web App

Aplicação full stack desacoplada para autenticação e gerenciamento de usuários. A solução combina API RESTful em Flask com autenticação baseada em sessão, frontend estático em HTML, CSS e JavaScript, containerização Docker e execução com Gunicorn. O backend foi implantado na Render, o frontend foi publicado via GitHub Pages e a imagem da API foi disponibilizada publicamente no Docker Hub.

Flask Flask-Login Flask-SQLAlchemy HTML / CSS / JavaScript SQLite Docker Gunicorn Render GitHub Pages Docker Hub
